# tree_pine

Świerk

- Docelowy rozmiar w grze: **80x170 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage3_fields_forest/props/` (nazwa `tree_pine.png`, kolejne warianty `tree_pine_2.png` ... `tree_pine_6.png`).
