# banner_torn

Podarty sztandar

- Docelowy rozmiar w grze: **35x72 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage3_fields_forest/props/` (nazwa `banner_torn.png`, kolejne warianty `banner_torn_2.png` ... `banner_torn_6.png`).
