# stone_big

Głaz

- Docelowy rozmiar w grze: **45x38 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage3_fields_forest/props/` (nazwa `stone_big.png`, kolejne warianty `stone_big_2.png` ... `stone_big_6.png`).
