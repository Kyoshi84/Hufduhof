# scarecrow

Strach na wróble

- Docelowy rozmiar w grze: **40x85 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage2_village/props/` (nazwa `scarecrow.png`, kolejne warianty `scarecrow_2.png` ... `scarecrow_6.png`).
