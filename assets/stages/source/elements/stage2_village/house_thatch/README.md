# house_thatch

Chata ze strzechą

- Docelowy rozmiar w grze: **130x150 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage2_village/props/` (nazwa `house_thatch.png`, kolejne warianty `house_thatch_2.png` ... `house_thatch_6.png`).
