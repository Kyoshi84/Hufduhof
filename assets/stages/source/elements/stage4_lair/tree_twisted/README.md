# tree_twisted

Skażone drzewo

- Docelowy rozmiar w grze: **110x150 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage4_lair/props/` (nazwa `tree_twisted.png`, kolejne warianty `tree_twisted_2.png` ... `tree_twisted_6.png`).
