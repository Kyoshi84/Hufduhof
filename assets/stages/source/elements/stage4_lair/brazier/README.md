# brazier

Kocioł z ogniem chaosu

- Docelowy rozmiar w grze: **30x65 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage4_lair/props/` (nazwa `brazier.png`, kolejne warianty `brazier_2.png` ... `brazier_6.png`).
