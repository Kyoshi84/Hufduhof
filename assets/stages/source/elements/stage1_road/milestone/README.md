# milestone

Kamień milowy

- Docelowy rozmiar w grze: **28x32 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage1_road/props/` (nazwa `milestone.png`, kolejne warianty `milestone_2.png` ... `milestone_6.png`).
