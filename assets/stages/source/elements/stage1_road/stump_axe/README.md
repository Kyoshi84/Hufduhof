# stump_axe

Pieniek z toporem

- Docelowy rozmiar w grze: **40x45 px** (1 piksel = 4/3 jednostki świata).
- Pivot: środek dolnej krawędzi PNG (punkt styku z podłożem).
- Element **podłączony do gry** – gra wczyta gotowy plik z folderu `props/` automatycznie.

Tu wrzucasz **surowe** pliki (wycięcie z panoramy, obraz w wyższej rozdzielczości, warstwy robocze).
Gotowy plik w rozmiarze docelowym trafia do `assets/stages/stage1_road/props/` (nazwa `stump_axe.png`, kolejne warianty `stump_axe_2.png` ... `stump_axe_6.png`).
